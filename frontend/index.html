Academic DBMS Curriculum Concepts

Quick-reference guide for external examiners and viva evaluations.

1. Normalization (1NF to 3NF)

  • 1NF: Multi-valued attributes eliminated. Atomic columns for each inventory cell.
  • 2NF: Removed partial dependencies by decomposing compound order lines into orders and order_items.
  • 3NF: Removed transitive dependencies: customer addresses moved to customers rather than living in orders.

2. ACID Compliance in Orders

  • Atomicity: Order creation and inventory deduction succeed together or both rollback.
  • Consistency: CHECK constraints prevent negative inventory (quantity_on_hand >= 0).
  • Isolation: Row-level locks (FOR UPDATE) prevent race conditions between concurrent orders.
  • Durability: Changes are written to persistent disk storage on commit.

3. Automated Triggers & Auditing

  • trg_audit_inventory_update: Fires AFTER UPDATE on inventory, recording old/new values.
  • trg_prevent_negative_stock: Fires BEFORE UPDATE, aborting updates if quantity drops below zero.
  • trg_update_order_totals: Calculates 18% GST and rolls up line items into the order header.

4. Views & Query Optimization

  • vw_low_stock_alerts: Simplifies complex JOIN logic across 4 tables for inventory managers.
  • vw_inventory_valuation: Pre-aggregated holding asset report.
  • B-Tree Indexes: Created on (product_id, warehouse_id) and (customer_id, order_date) to minimize full-table scans.
